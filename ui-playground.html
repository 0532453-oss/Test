Accordion / Expandable Cards

How does workspace isolation work?

▼

FlexDesk uses Prisma extensions to automatically scope all database queries to the current workspace. A WorkspaceInterceptor extracts the workspaceId from your JWT token, and the Prisma extension injects WHERE clauses on every read and sets workspaceId on every create operation.

Can I use FlexDesk offline?

▼

Yes! FlexDesk uses an offline-first architecture with IndexedDB sync. Changes made while offline are queued and automatically synced when connectivity is restored. Conflict resolution handles any data discrepancies.

What security measures are in place?

▼

FlexDesk includes rate limiting (100 req/60s), body size limits, Helmet security headers, CSP policies, workspace-scoped RLS, JWT auth with refresh tokens, and Google OAuth. A full security audit identified and fixed 60+ issues.
