### Data Provider
- ra-core's GetListParams has optional `pagination` and `sort` — use `?.` with defaults
- ra-core's `delete` return type uses generics — use `as any` for previousData fallback
- Backend returns plain arrays from GET /resource (not {data, total}) — handle both formats
- Workspace ID is embedded in JWT and extracted server-side by WorkspaceInterceptor; also sent as x-workspace-id header
- Custom data provider preferred over ra-data-json-server since backend uses simple REST, not JSON Server format
- API base path is /api/v1 (e.g., /api/v1/customers, /api/v1/jobs)
- httpClient wrapper attaches JWT from localStorage via getAccessToken() helper
