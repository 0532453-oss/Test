- US-021: Implement sync push (local to server)
  - sync_queue table already existed in schema.ts and SyncQueueItem model from US-019
  - Added pushSync() to src/db/sync.ts: queries sync_queue for PENDING items sorted by created_at ASC (FIFO)
  - For each item: marks as PROCESSING, makes API call via apiClient.request(url, method, data)
  - On 2xx success: removes item from queue via destroyPermanently()
  - On 409: marks item as CONFLICT status (for US-023 conflict resolution UI)
  - On 4xx (not 409): marks item as FAILED permanently
  - On network error / 5xx: retries with exponential backoff (1s, 2s, 4s, 8s, 16s), max 5 retries
  - After max retries: marks as FAILED
  - Created enqueueMutation(endpoint, method, payload, entityType, entityId) helper for screens to queue offline mutations
